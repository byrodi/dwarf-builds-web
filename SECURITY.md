# Security Policy

## Supported versions

Security fixes go into the `main` branch, which is what [dwarfbuilds.pages.dev](https://dwarfbuilds.pages.dev) runs.

## Reporting a vulnerability

Do not open a public issue. Report privately through GitHub:
https://github.com/byrodi/dwarf-builds-web/security/advisories/new

Include the affected page or API route, steps to reproduce and the impact you expect. Reports are acknowledged within 14 days. A confirmed vulnerability is fixed on the live site and disclosed through a GitHub Security Advisory, normally within 90 days of the report.
