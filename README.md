# Dwarf Builds website

Browse and share Deep Rock Galactic builds as codes for the Dwarf Builds mod.

Live at [dwarfbuilds.pages.dev](https://dwarfbuilds.pages.dev). The mod and the game data exporter are in
[byrodi/dwarf-builds-drg](https://github.com/byrodi/dwarf-builds-drg).

## Features

- Browse builds by class, weapon and overclock, newest or most liked.
- Each build shows its loadout and stats the way the game does.
- Make a build in an editor shaped like the game's loadout screen.
- Sign in with Steam to publish; descriptions take Markdown.
- Copy a build code, and the mod in game offers to take it.

## How it is built

Cloudflare Pages: static files in `public/` and Pages Functions in `functions/`, with the D1 database
`dwarfbuilds-db`. No framework and no build step.

Game data (`public/data/` and `public/img/`) is not in git. `Tools/dwarfbuilds_export.py` in the mod repository
reads it from an installed game and writes it here; in the mod repository this site is the `Web` submodule.

## Layout

| Path | What |
| --- | --- |
| `public/` | Static site (SPA). `public/data/` and `public/img/` are generated by `Tools/dwarfbuilds_export.py` (not in git). |
| `public/js/shared/code.js` | DB2 build code: parse, encode, validate against game.json, rebuild from asset names. Used by the browser and the Functions. |
| `functions/api/` | JSON API (`_middleware.js`: CSRF guard, errors, security headers, session). |
| `functions/b/[id].js` | `/b/<id>`: index.html with Open Graph tags (replaces `<!--og-->`). |
| `functions/_lib/` | Helpers: session cookie, Steam OpenID, Steam profile, game data, builds, profanity check. |
| `migrations/` | D1 schema. |
| `scripts/check-secrets.mjs` | Secret scan of `public/` and `functions/`. |
| `scripts/make-vectors.mjs` | Writes `tests/code_vectors.json` from the test fixture. |
| `tests/` | `node --test` unit tests; `tests/fixtures/game.sample.json` is a small game.json. |

## API

All responses are JSON; errors are `{"error": "..."}`. Times are unix milliseconds.
POST/PUT/DELETE need `Content-Type: application/json`, `X-Dwarfbuilds: 1` and a same-origin `Origin`
(a browser `fetch` from the site sends Origin by itself).

| Method | Path | Answer |
| --- | --- | --- |
| GET | `/api/me` | `null` or `{steamId, name, avatar, admin, banned}` |
| GET | `/api/auth/login?next=/path` | redirect to Steam; back to `next` when signed in, to `/?signin=failed` on failure |
| POST | `/api/auth/logout` | `{ok}` |
| GET | `/api/builds?class=D\|driller&item=<itemId>&oc=<ocId>&q=&sort=new\|top&page=` | `{builds: [card], page, pageSize: 24, hasMore, sort}` |
| GET | `/api/builds/:id` | `{id, class, title, description, code, storedCode, rebuilt, missing, primaryItem, secondaryItem, primaryOc, secondaryOc, likes, liked, hidden, dataVersion, createdAt, updatedAt, author, canEdit, canDelete, canHide}` |
| POST | `/api/builds` `{title, description, code}` | 201 `{id, code}` (canonical code) |
| PUT | `/api/builds/:id` (owner), same body | `{id, code}` |
| DELETE | `/api/builds/:id` (owner or admin) | `{ok}` |
| POST | `/api/builds/:id/like` | `{liked, likes}` (toggle) |
| POST | `/api/builds/:id/report` `{reason}` | `{ok}` |
| POST | `/api/builds/:id/hide` `{hidden}` (admin) | `{id, hidden}` |
| GET | `/api/users/:steamid?page=` | `{user: {steamId, name, avatar, createdAt}, builds: [card], page, pageSize, hasMore}` |

card = `{id, class, title, code, primaryItem, secondaryItem, primaryOc, secondaryOc, likes, hidden, createdAt, updatedAt, author: {steamId, name, avatar}}`.
Item and OC values are game.json ids (`FlameThrower`, `OC_Flamethrower_ClipSize_B`). Titles and descriptions are
plain text: show them with `textContent`, never `innerHTML`.

Titles and descriptions with profanity (English or Russian) are refused with 400: `functions/_lib/profanity.js`,
the [obscenity](https://github.com/jo3-l/obscenity) package plus a short list of Russian roots.

## Local dev

```sh
npm install
cp .dev.vars.example .dev.vars      # dev-only values; .dev.vars is gitignored
npm run migrate:local
npm run dev                          # http://localhost:8788
```

Dev sign-in without Steam: `http://localhost:8788/api/auth/dev?steamid=76561197960287930&next=/me`
(only with `DEV_LOGIN=1` in `.dev.vars` and a localhost host). Creating builds needs `public/data/game.json`
(run the exporter).

## Tests

```sh
npm test                 # unit tests
npm run check-secrets    # secret scan
node scripts/make-vectors.mjs   # after changing the fixture or code.js
```

## Deploy

```sh
npm run deploy           # check-secrets, tests, then wrangler pages deploy --branch main
npm run migrate:remote   # only when migrations/ changed; try migrate:local first
```

Never `wrangler deploy`, never `--force`.

## Secrets

Only in Cloudflare Pages secrets (never in files here): `SESSION_SECRET` (cookie HMAC), `STEAM_API_KEY`
(optional; without it the public profile XML is used), `ADMIN_STEAM_IDS` (comma list of SteamID64).
`DEV_LOGIN` must never be set in production.
